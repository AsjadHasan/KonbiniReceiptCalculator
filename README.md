# KonbiniReceiptCalculator by Python 
Topics: input(), type conversion, loops, conditionals, f-strings
A convenience store in Japan charges 8% consumption tax on food items and 10% on other items. Write a program that prints a receipt for a customer.
Read the number of items, then each item's name, price (yen, tax-excluded) and type (food or other).
If the type is invalid, print Invalid type and read the type again.
Round each item's tax down to whole yen.
Print each item, then the subtotal, 8% tax total, 10% tax total and total before discount.
If the total is ¥1,000 or more, apply a ¥50 discount. Print the discount and final total.
